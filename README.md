# TP d'Outils fondamentaux (TP1 - TP6)
Les fichiers peuvent être retrouvés dans le répertoire nommé /TPs.
Chaque exercice de TP a été rassemblé en un seul fichier, tous séparés par un répertoire.

# Projet-Python-RPG-Engine
Un projet Python pour le cours d'Outils fondamentaux, à la suite des TP1 à TP6.
Inspiré du style RPG dont certains jeux vidéo se servent, il peut être retrouvé dans le répertoire nommé /RPG-Engine.

Certaines fonctions des derniers TP ainsi que certaines se trouvant vers le bas du code du projet (les mêmes fonctions que celles des TP m'ayant bloqué)
ont été assistées et expliquées par l'IA car elles étaient, selon moi, assez difficiles à comprendre.
Cependant, l'idée derrière chaque code et chaque formule a été lue et relue, et a été en général comprise.
